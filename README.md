# Игра «Жизнь» Джона Конвея

![C](https://img.shields.io/badge/C-90-blue?logo=c)

Консольная реализация **клеточного автомата "Жизнь"** на языке Си с использованием библиотеки **ncurses**.

Программа предоставляет редактор поля (Vim-like), несколько настроек поля, симуляции и правил. Также есть поддержка загрузки/сохранения состояний.

![Demo](media/demo.gif)

- **Редактор поля**
  Перемещение курсора по клавишам `h`/`j`/`k`/`l` (Vim-style) или на стрелочки. Изменение состояния клетки на клавишу `e`, запуск симуляции на `Enter`.

- **Управление симуляцией**
  - `p` — пауза / возврат
  - `s` — Сохранить текущее состояние (при паузе)
  - `q` — Выход в главное меню

- **Настройки**
  - Граничные случаи: `dead` (клетки снаружи считаются мертвыми) или `toroidal` (периодические границы, «тор»)
  - Время между поколениями (в миллисекундах)
  - Размер поля (строки × столбцы) с автоматическим ограничением по терминалу.

- **Загрузка/сохранение файлов**
  - Файлы для сохранения и загрузки имеют простой формат (размеры поля + таблица `0`/`1`)
  - Сохранение и загрузка происходят через директорию `areas/` 

- **Модульный код**
  - Написан в стандарте C90
  - Модули с единственной ответственностью (`area`, `game`, `ui`, `file_io`, `utils`)
  - Структура обработки ошибок `status_t`
  - Защита от утечек памяти: `calloc`, корректное `free` и тщательные проверки на `NULL`


## Установка

### Требования
- Linux или macOS
- библиотека **ncurses** 
- компилятор **GCC**
- программа **make**

#### Установка зависимостей:

**Debian / Ubuntu**
```bash
sudo apt install libncurses-dev make
```

**Arch / Manjaro**
```bash
sudo pacman -S ncurses make
```

**macOS (Homebrew)**
```bash
brew install ncurses make
```

### Сборка

```bash
git clone https://github.com/Vindheitt/Conway-Life-C.git
cd Conway-Life-C
make
```

### Запуск

```bash
./life
```

## Управление

| Клавиша      | Действие                        |
|--------------|---------------------------------|
| `h` / `←`    | Курсор влево                    |
| `j` / `↓`    | Курсор вниз                     |
| `k` / `↑`    | Курсор вверх                    |
| `l` / `→`    | Курсор вправо                   |
| `e`          | Изменить состояние клетки       |
| `Enter`      | Запустить симуляцию             |
| `q`          | Выход                           |
| `s`          | Сохранить состояние             |
| `p`          | Пауза / продолжить              |

## Архитектура
Проект построен вокруг идеи единственной ответственности:
- `area` — управление состоянием поля
- `game` — логика симуляции
- `ui` — отрисовка через ncurses
- `file_io` — загрузка/сохранение
- `utils` — вспомогательные функции

Статус-код `status_t` используется для единообразной обработки ошибок.

## Формат файла

Сохраненные файлы имеют формат:

```
<rows> <cols>
<row 1>
<row 2>
...
```

Приммер для (`glider.txt`):

```
3 3
010
001
111
```

- `0` — Мертвые клетки  
- `1` — Живые клетки
